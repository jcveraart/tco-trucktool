Website-overzicht

Hoe de site is gebouwd, wat elke pagina doet, wat je eraan test en wat er beter kan. Kies per pagina een status, vink testen af en schrijf notities met een categorie erbij. Alles wordt automatisch in deze browser bewaard; niets wordt verstuurd.

Zo is de site gebouwd: één groot bronbestand (index.html, ± 860 KB) bevat de hele app. Het script scripts/seo.mjs maakt daar 48 statische pagina's van (23 routes × Nederlands/Engels) met per pagina een eigen titel, omschrijving en canonical. Wijzigen doe je altijd in de bron, daarna: node scripts/i18n.cjs → node scripts/seo.mjs → node --test tests/*.test.cjs (27 tests) → commit en push. Publicatie loopt via GitHub Pages. De volledige uitleg staat in docs/website-overzicht.md.
Zo gebruik je dit overzicht: na een wijziging loop je per pagina de testlijst af en vink je af wat je echt hebt geprobeerd. Notities schrijf je vrij — kies er wel een categorie bij (SEO, inspiratie, verbetering, taalgebruik, bug of vraag), dan kun je er later op filteren. De filterbalk hierboven zoekt op paginastatus, notitiecategorie en tekst tegelijk.
