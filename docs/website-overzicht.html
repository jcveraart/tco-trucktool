Website-overzicht

Hoe de site is gebouwd, wat elke pagina doet, wat je eraan test en wat er beter kan. Kies per pagina een status en schrijf er vrij je notities bij — alles wordt automatisch in deze browser bewaard, niets wordt verstuurd.

Zo is de site gebouwd: één groot bronbestand (index.html, ± 860 KB) bevat de hele app. Het script scripts/seo.mjs maakt daar 48 statische pagina's van (23 routes × Nederlands/Engels) met per pagina een eigen titel, omschrijving en canonical. Wijzigen doe je altijd in de bron, daarna: node scripts/i18n.cjs → node scripts/seo.mjs → node --test tests/*.test.cjs (27 tests) → commit en push. Publicatie loopt via GitHub Pages. De volledige uitleg staat in docs/website-overzicht.md.
Ontwikkelen en testen: draai de site lokaal met python -m http.server 8000 in de hoofdmap en open http://127.0.0.1:8000/. Wijzig nooit een gegenereerde pagina met de hand. De 27 automatische tests dekken metadata, sitemap, taalversies en dat scripts compileren; alles wat je kunt aanklikken test je zelf — per pagina staat onder Testen wat je minimaal doorloopt. Na elke wijziging: pagina opent zonder consolefouten · kernactie werkt · taalwissel neemt de stand mee · mobiel bruikbaar · geen netwerkverkeer zonder toestemming. Valkuilen: nieuwe tekst ook vertalen · eerst git pull (de SEO-workflow commit zelf) · groene tests zeggen niets over aanklikbaarheid.
