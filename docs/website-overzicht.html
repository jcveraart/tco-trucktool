Website-overzicht — Stekker of Diesel

Hoe de site is gebouwd, wat elke pagina doet, wat je eraan kunt testen en wat er beter kan. Voor ontwikkeling en testen, niet alleen SEO. Kies per pagina een status en schrijf per pagina vrij je notities erbij (kladblok, geen vast format); alles wordt automatisch in deze browser bewaard. Niets wordt verstuurd.

Zo is de site gebouwd: één groot bronbestand (index.html, ± 860 KB) bevat de hele app. Het script scripts/seo.mjs maakt daar 48 statische pagina's van (23 routes × Nederlands/Engels) met per pagina een eigen titel, omschrijving en canonical. Wijzigen doe je dus altijd in index.html, daarna: node scripts/i18n.cjs → node scripts/seo.mjs → node --test tests/*.test.cjs (27 tests) → commit en push. Publicatie loopt via GitHub Pages. De volledige uitleg en de verbeter-backlog staan in docs/website-overzicht.md en hieronder per pagina.
Ontwikkelen en testen: draai de site lokaal met python -m http.server 8000 in de hoofdmap en open http://127.0.0.1:8000/. Wijzig nooit een gegenereerde pagina met de hand — altijd de bron (index.html of scripts/seo.mjs), daarna i18n → generator → tests (zie hierboven) → commit. De 27 automatische tests dekken metadata, sitemap, taalversies en dat scripts compileren; alles wat je kunt aanklikken moet je zelf testen. Gebruik deze tracker daarvoor: per pagina staat onder Testen wat je minimaal doorloopt na een wijziging.

Testprotocol (na elke wijziging)

Automatisch (altijd): node scripts/i18n.cjs → node scripts/seo.mjs → node --test tests/*.test.cjs (27/27 groen).
Met de hand (per gewijzigde pagina, zie "Testen" op de kaart): pagina opent zonder consolefouten · kernactie werkt (rekenen, filteren, formulier) · taalwissel NL/EN blijft op dezelfde pagina en neemt de stand mee · mobiel (smal scherm) bruikbaar · herladen bewaart voorkeuren waar dat hoort · zonder toestemming geen netwerkverkeer naar GA/Supabase.
Bekende valkuilen: gegenereerde pagina's nooit met de hand wijzigen (worden overschreven) · nieuwe tekst ook vertalen, anders blijft hij Nederlands op Engelse pagina's · de SEO-workflow commit zelf gegenereerde pagina's — haal eerst op (git pull) voordat je pusht · de rekenkern heeft een eigen test in de browserconsole-modus van de testsuite; een groene metatest zegt niets over wat je kunt aanklikken.
